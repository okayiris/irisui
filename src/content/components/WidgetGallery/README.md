# WidgetGallery

The four widget looks (glass, pattern, ring, list and type), each in the four sizes (small, wide, tall, large) with changing topics, as the widget lab draws them.

A showcase page, one of three: the demo data over twelve topics is in `WidgetData`, scrolling, pictures and the full Groceries screen with ticking off in `WidgetScreens`. Build real widgets with `Widget`, `Pattern`, `PageDots` and `Topic`; the rules are in `systems.md` (Widgets) and `screens.md`.
