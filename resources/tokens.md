# Tokens

| token | value | what it is for |
| --- | --- | --- |
| `--bg` | `#07090c` | Page background of every surface. Never grey, never white. |
| `--fg` | `#e8f2f7` | Titles and primary text on bg. |
| `--dim` | `#8fa3b0` | The line under a title, secondary text. |
| `--faint` | `#5a6b78` | Chevrons, section labels, version line. Not for body text (3.5:1). |
| `--line` | `#1b2430` | Dividers. |
| `--accent` | `#7dd3fc` | Ice blue: what is active (tab, link, action pill). |
| `--accent-ink` | `#07171f` | Text on an accent fill. |
| `--violet` | `#8b5cf6` | Only for on (toggles) and the ring. |
| `--violet-light` | `#a78bfa` | Hover and edges of violet things. |
| `--error` | `#f87171` | Destructive only (Delete account). |
| `--ok` | `#4ade80` | Done. |
| `--wait` | `#fde68a` | Waiting. |
| `--glass` | `rgba(180, 225, 255, .07)` | Fill of every card. |
| `--edge` | `rgba(190, 230, 255, .14)` | 1px stroke of every card. |
| `--pad-card` | `14px` | Padding inside a card. |
| `--gap` | `12px` | Between cards on a page. |
| `--gutter` | `16px` | Page side margin. |
| `--radius-card` | `18px` | Every card, row and sheet. |
| `--radius-button` | `20px` | Large full-width buttons. |
| `--radius-pill` | `999px` | Pills, tabs, small buttons, toggles. |
| `--font-text` | `Inter, -apple-system, "SF Pro Text", system-ui, "Segoe UI", Roboto, sans-serif` |  |
| `--font-display` | `Inter, -apple-system, "SF Pro Display", system-ui, "Segoe UI", Roboto, sans-serif` |  |
| `--font-mono` | `ui-monospace, "SF Mono", SFMono-Regular, Menlo, Consolas, monospace` |  |
| `--text-hero` | `700 34px/40px var(--font-display)` | Big headline on a hero or post. |
| `--text-page-title` | `700 28px/34px var(--font-display)` | Page title in the app. |
| `--text-row-title` | `400 17px/22px var(--font-text)` | Card and row titles. |
| `--text-body` | `400 15px/20px var(--font-text)` | Running text (body text). |
| `--text-sub` | `400 12px/16px var(--font-text)` | The dim line under a title. |
| `--text-tab` | `400 13px/16px var(--font-text)` | Tab bar labels. |
| `--text-label` | `500 10.5px/14px var(--font-mono)` | Section labels, caps, faint. |
| `--text-value` | `400 12px/16px var(--font-mono)` | Times, counters. |
